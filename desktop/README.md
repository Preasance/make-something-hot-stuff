# Ctrl + 마우스 휠 (Windows)

아바타는 키보드 입력을 직접 읽지 못하므로 이 외부 프로그램이 VRChat 공식 OSC 입력으로 두 파라미터를 보냅니다. 클라이언트 수정이나 관리자 실행은 필요하지 않습니다.

1. python.org의 Windows Python 3를 설치합니다.
2. 이 폴더에서 터미널을 열고 `py -m pip install pynput==1.8.1`을 실행합니다.
3. VRChat 원형 메뉴의 Options → OSC → Enabled를 켭니다. 한국어에서는 옵션/OSC/활성화로 표시될 수 있습니다.
4. `py zoom_control.py`를 실행하고 창을 열어 둡니다.
5. VRChat을 선택하고 원형 메뉴를 닫습니다. Ctrl+휠 위로 배율이 5%씩 증가하며 자동으로 Optics가 켜집니다. 아래로 내려 0%가 되면 꺼집니다. F8도 끄기입니다.

주의: 이 보조 프로그램의 Windows 입력과 게임 연동은 아직 실기 검증하지 못했습니다. OSC 패킷 인코딩만 검사했습니다. 휠 입력을 차단하지 않으므로 게임 자체의 Ctrl/휠 동작도 함께 일어날 수 있습니다. VRChat이 전경일 때만 반응합니다. 보조 프로그램은 배율을 0에서 시작하며 게임 메뉴와 양방향 동기화하지 않습니다. 테스트 중에는 프로그램으로만 배율을 조절하세요. 아바타 변경 시 현재 값을 다시 보내려면 휠을 움직이세요.

OSC는 localhost UDP 9000으로 Kiroshi/Amount(float), Kiroshi/Enabled(bool)를 보냅니다. 게임 OSC 설정에서 해당 파라미터 입력이 활성화되어 있어야 합니다. SDK 테스트 아바타에서 입력이 되지 않으면 OSC 설정/파라미터 매핑 확인이 필요합니다. 프로그램을 강제 종료하면 끄기 패킷을 보낼 수 없으므로 게임 메뉴의 Optics를 직접 끄세요.
